# Bhuvaneshwari Birthday Website ❤️

A romantic birthday website built with only:
- HTML
- CSS
- JavaScript

## Folder structure

```text
Bhuvaneshwari_Birthday_Website/
├── index.html
├── style.css
├── script.js
├── README.md
└── images/
    ├── bhuvaneshwari-collage.jpg
    └── bhuvaneshwari-portrait.png
```

## Run it on your computer

Simply double-click `index.html`.

## Publish on GitHub Pages

1. Create a GitHub account if you don't already have one.
2. Create a new repository, for example:
   `bhuvaneshwari-birthday`
3. Upload:
   - `index.html`
   - `style.css`
   - `script.js`
   - the entire `images` folder
4. Open the repository's **Settings**.
5. Open **Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select the `main` branch and `/ (root)`.
8. Save.
9. GitHub will give you a public website address.

## Important

Keep the folder names and image filenames exactly the same unless you also change
the paths inside `index.html`.

The website uses the photos supplied for this birthday page. Make sure you have
permission from the person in the photos before publishing them publicly.

## Optional music

No music file is included, so the site does not depend on copyrighted audio.
If you have your own audio and want music, add an MP3 file and an audio player
to `index.html`.
